Visual guide

VeriTrace, in pictures

VeriTrace inspects any document — a PDF, a Word file or pasted text — for the hidden fingerprints, invisible characters and watermark signatures that machine-generated files tend to carry. It shows them in a layered forensic view and can rebuild a clean copy that keeps your wording and facts intact, running for free entirely inside your own browser.

The real-world problem, and how it's solved

Machine-generated documents carry traces most tools ignore. Each problem on the left maps to one specific VeriTrace check on the right.

What happens when you scan a document

A scan runs four checks in order, behind a strict input firewall, then hands you a visual report. The sanitizer and any external call only run when you ask.

Four layers over the same text

The document passes through four independent layers, from raw bytes up to a clean rebuild. The first three gather evidence (purple); the last one acts on it (teal).

How the sanitizer never loses a fact

It locks every number, date, name and skill first, edits only the prose around them, and refuses any edit that would drop one — falling back to a loss-free clean-up instead.

Five guardrails around every request

The input is untrusted text from the open internet, so each request passes through five independent defenses before anything runs.

Two ways in: demo or your own file

Explore it instantly with pre-loaded artifacts, or run it on your own document. Either way, nothing leaves your machine.
